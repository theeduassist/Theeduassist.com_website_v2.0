## Translation vs Localization: The Core Difference

When a company decides to launch an online training program globally, they often ask for "course translation." But what they actually need is "course localization."

Understanding the difference between the two prevents costly mistakes, broken course designs, and confused learners.

### What is Translation?

**Translation** is the process of converting text (or speech) from a source language into a target language. Its primary goal is accuracy.

A translation agency will take an English script and return a Spanish script. If the source says "Click the button," the translation will accurately instruct the user to click the button in Spanish.

### What is Localization?

**Localization** is the holistic adaptation of a digital product (like an eLearning course) for a specific region or locale. It encompasses translation, but goes much further.

Localization ensures the course *feels* as if it was originally created for the target audience, and that the digital format *functions* correctly.

## Five Key Differences in eLearning

Here is how translation and localization differ when applied to digital training.

### 1. Cultural Adaptation
*   **Translation:** Converts a scenario about a "baseball game" directly into the target language.
*   **Localization:** Recognizes that baseball is not popular in the target region and rewrites the scenario to be about football (soccer), ensuring the learning analogy actually makes sense to the audience.

### 2. Layout and Engineering (Text Expansion)
*   **Translation:** Returns accurate German text, which happens to be 30% longer than the English source text.
*   **Localization:** An engineer takes that German text, imports it into Articulate Storyline, and manually adjusts the font sizes, expands the text boxes, and redesigns the slide layout so the expanded text actually fits on the screen without overlapping images.

### 3. Visuals and Media
*   **Translation:** Leaves images untouched.
*   **Localization:** Replaces an image of an American power outlet with a European power outlet. It updates a screenshot of the English software UI to a screenshot of the Spanish software UI.

### 4. Technical Interactivity
*   **Translation:** Translates the words "True" and "False".
*   **Localization:** Re-programs the True/False quiz variables in the authoring tool so that clicking the translated buttons still sends the correct scoring data to the Learning Management System.

### 5. Formatting Standards
*   **Translation:** May translate dates literally.
*   **Localization:** Adapts date formats (e.g., changing MM/DD/YYYY to DD/MM/YYYY), currencies, units of measurement (imperial to metric), and time formats (12-hour to 24-hour).

## Which Do You Need?

If you are only dealing with a simple text document (like a plain Word file or a static PDF policy), high-quality **translation** is usually sufficient.

If you are dealing with a digital experience—an interactive SCORM course, a software training video with voiceovers and on-screen actions, or a Help Center with navigation menus—you require **localization** to ensure the final product is usable and professional.
